# Main Line Auto Works

Redesigned site for Main Line Auto Works, West Chester, PA. Static HTML/CSS/JS, no build step.

- `index.html` – the page
- `styles.css` – all styling
- `main.js` – mobile menu, service photo switcher, window tint shade picker
- `assets/img/` – photos and logo pulled from the current Squarespace site

To preview locally, open `index.html` in a browser (or run `python3 -m http.server`).

To host on GitHub Pages: Settings → Pages → deploy from `main`, root folder. Pointing mainlineautoworks.com here means adding a `CNAME` file and updating DNS at the registrar.

Booking and gift cards still link out to Square.
